# 耳虫音乐 v1.1.41

网易云音乐下载 / 播放 Android 客户端。

## 本版更新

- 项目名统一为 **EarBug_music**（Gradle 项目名、主题、目录、文档）
- 评论弹窗显示**当前播放歌曲**（修复队列下标错位问题）
- 封面分级：列表缩略图 400px / 下载缩略图 260px/**播放页原图**
- 缩略图圆角裁剪（RoundImageView）
- 新增「红心歌曲」页与收藏按钮（♡ / ♥）
- 同时下载最多 5 首（原为串行）
- 歌词改为**原文 + 翻译两行**，每句完整可见
- 播放页上滑打开歌词；封面放大到 310dp
- 通知栏：停止后不再重生通知，按钮点击有 Toast 反馈
- 弹窗动画改为淡入 + 上浮
- 冷启动恢复上次播放（暂停在上次位置）
- 列表封面预置占位图、搜索后回到顶部、存储权限延迟到首次下载

## 安装

1. 下载 `EarBug_music-v1.1.41-debug.apk`
2. 允许「安装未知来源应用」后安装
3. 首次下载会请求存储权限（Android 9 及以下）

## 说明

- 包名：`com.zhaoguanghao.earbugmusic`（旧包名 `com.zhaogunghao.*` 的版本需先卸载）
- 下载目录：`/storage/emulated/0/Download/耳虫音乐/`
- 无损依赖第三方解析服务，偶发失败会自动重试；标准 / 较高 / 极高走官方接口

> 仅供学习研究，请支持正版音乐。
